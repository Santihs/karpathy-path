¿Cuál es la diferencia entre dimensión y rank?

---

Dimensión es propiedad de un ESPACIO vectorial (tamaño de cualquier base suya). Rank es propiedad de un SET de vectores cualquiera (dim de lo que ese set genera) — un set puede tener rank menor que su cardinalidad si hay vectores redundantes. rank(S) = dim(Span S).
